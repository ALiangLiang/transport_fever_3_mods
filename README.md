# Animal Radar

> **專為 Transport Fever 3 (TF3) 打造的全地圖動物偵測雷達與鏡頭聚焦系統**  
> **Mod ID**: `aliangliang_animal_radar`  
> **作者**: ALiangLiang  
> **版本**: 1.0.0 (Revision 1)

---

## 📌 模組功能簡介

在《Transport Fever 3》地圖中棲息著各種動物（如鹿、棕熊、狐狸、狼、美洲獅、灰鶴、老鷹、海鷗、鮭魚魚群、七彩神仙魚魚群等）。本模組提供專屬的「動物雷達視窗」：
1. **即時掃描地圖**：自動偵測地圖上的所有動物實體。
2. **純淨種類呈現**：精簡展示動物的物種名稱與實體編號，去除多餘的座標、距離與狀態標註。
3. **物種分頁標籤**：依據地圖上實際存在的動物物種動態生成分頁標籤（例如「全部」、「鹿」、「棕熊」、「七彩神仙魚魚群」等），點擊即可快速篩選指定物種。
4. **一鍵鏡頭跳轉與追蹤**：點擊動物項目右側的「觀察聚焦」按鈕，鏡頭會立即平滑移動至該動物身旁，並持續跟隨追蹤！
5. **鏡頭模式切換**：支援「跟隨」與「聚焦」雙模式切換。

---

## 🎮 遊戲內操作方式

1. **開啟雷達視窗**：
   * 在遊戲畫面左上方工具列（資料圖層旁邊的模組工具列區域），點擊 **「動物雷達」** 按鈕即可彈出雷達視窗；再次點擊即可關閉。
2. **物種篩選**：
   * 點擊上方的物種分頁標籤（如「全部」、「鹿」、「灰鶴」等），快速過濾列表中只顯示該物種。
3. **鏡頭跳轉**：
   * 點擊任意動物右側的 **「觀察聚焦」**，遊戲鏡頭將立即平滑移動至該動物身旁並跟隨追蹤。
4. **切換鏡頭模式**：
   * 視窗頂部按鈕可切換 **「鏡頭模式: 跟隨」**（鏡頭隨動物移動）或 **「鏡頭模式: 聚焦」**（僅將視野移至該位置）。
