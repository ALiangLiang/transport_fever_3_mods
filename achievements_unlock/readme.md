# Achievements Unlock / 成就解鎖器

An in-game achievement overview and one-click unlocking utility for Transport Fever 2.

## Features
- **Quick Access**: Convenient button located in the top-left corner of the game screen to open the achievement window anytime.
- **In-Game Window**: View all 45+ official achievements with live progress, names, descriptions, and icons.
- **One-Click Unlock**: Click "Unlock" next to any locked achievement to trigger `api.gui.achievements.unlockAchievement` instantly.
- **Unlock All**: Instantly unlock all remaining achievements with one button.
- **Filter Tabs**: Filter by "All", "Locked", and "Unlocked".
- **Confirmation Dialog**: Popup confirmation dialog before unlocking (single or all) to prevent accidental clicks, as achievements cannot be re-locked.
- **Zero Emojis**: Fully compatible with game fonts.
