# UFO Summoner (幽浮召喚器)

> **專為 Transport Fever 3 (TF3) 打造的手動 UFO 召喚與外星光束吸牛追蹤系統**  
> **Mod ID**: `aliangliang_ufo_summoner`  
> **作者**: ALiangLiang  
> **版本**: 1.0.0 (Revision 1)

---

## 模組功能簡介

在《Transport Fever 3》中內建了官方的幽浮彩蛋（UFO Easter Egg）與專屬成就「第三類接觸」（Encounter of the 3rd Kind / `ach_ufo`）。在原生遊戲中，UFO 需等待數年才會極為罕見地隨機出現。

本模組提供專屬的「幽浮召喚控制台」：
1. **專屬工具列按鈕**：點擊畫面左上角主工具列的「UFO」按鈕即可快速開啟控制面板。
2. **手動一鍵召喚**：即時呼叫神秘外星飛碟進場，無需枯等遊戲時間。
3. **空域雷達狀態**：即時掌握當前空域中是否有活躍飛碟、目標牛隻與光束吸牛階段（高速進場、鎖定目標、光束牽引、加速撤離）。
4. **一鍵鏡頭跟隨追蹤**：支援一鍵將鏡頭切換為跟隨「飛碟」或跟隨「目標牛隻」，近距離欣賞光束吸牛過程。
5. **解鎖成就得力助手**：對於完成「第三類接觸」（Encounter of the 3rd Kind）成就有極大幫助，無需枯等稀有隨機事件。

## 遊戲內操作方式

1. **開啟控制面板**：
   * 在遊戲畫面左上方工具列，點擊 **「幽浮」** 按鈕即可彈出控制視窗。
2. **召喚飛碟**：
   * 點擊面板底部的 **「召喚飛碟」** 按鈕。
   * 若地圖上建有**牲畜農場（Livestock Farm）**且有放牧牛隻，飛碟將從地圖外緣全速俯衝進場並鎖定牛隻！若無農場也會自動在鏡頭前方觸發彩蛋。
3. **鏡頭追蹤**：
   * 當飛碟進場後，面板中會顯示飛碟實體編號與當前狀態。
   * 點擊 **「追蹤飛碟」** 或 **「追蹤牛隻」** 即可平滑移動鏡頭並鎖定跟隨。
